# Constraint Validation Records (CVR)

Registro dos vereditos de validação de constraints, conforme o
**Constraint Validation Protocol** (`../constraint-validation-protocol.md`).

**Estado atual: zero CVRs.** Nenhuma constraint (C1–C7) foi fechada como
Validated/Reformulated/Rejected — todas permanecem *candidatas*, validação
pendente (domínio + harness). O diretório vazio é intencional: nada entra na
cadeia antes de sobreviver ao protocolo.

Formato: `CVR-<nn>-<slug>.md` com os campos do §5 do protocolo
(Constraint, Origem, Hipótese, Evidência favorável, Evidência contrária,
Cenários que a falsificam, Status, Data da decisão, Próximo passo).
