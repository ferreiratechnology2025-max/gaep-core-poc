# Problem Definition Records (PDR)

Registro dos vereditos sobre o próprio Problema (P0), conforme o
**Problem Definition Protocol** (`../problem-definition-protocol.md`).

**Estado atual: zero PDRs.** P0 está em v1.0.0, *Proposed* (rascunho — a
validar com o domínio). O diretório vazio é intencional: nenhum problema
entra como axioma; a validação de P0 também é um processo auditável.

Formato: `PDR-<nn>-<slug>.md` com os campos do §6 do protocolo
(Problema+versão, Origem, Sinais de invalidação, Classificação da mudança,
Impacto na árvore, Registro de propagação, Data da decisão, Próximo passo).
